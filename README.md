
# Serpantinum Native

Proyek shell desktop native untuk CachyOS + Hyprland.

## Tujuan
- Membangun ulang fitur shell secara bertahap.
- Mempelajari C++ dan teknologi desktop Wayland.
- Mengutamakan penggunaan RAM yang efisien.
- Mempertahankan kestabilan desktop.

## Target perangkat
- OS: CachyOS Linux
- Compositor: Hyprland
- CPU: Intel Core i5-1135G7
- RAM: 8 GB
- GPU: Intel Iris Xe

## Rencana pengerjaan
1. Audit fitur Serpantinum.
2. Mengukur penggunaan RAM awal.
3. Membuat prototipe bar native.
4. Mengintegrasikan Hyprland IPC.
5. Menambahkan fitur secara bertahap.
6. Menguji dan mengoptimalkan performa.
